**中文**

- **新增** 引入 `AuxmoAudioEngine` 实时音频图核心：每个应用作为独立 `AudioAppSource` 节点链（捕获、增益/静音、均衡器、空间、动态与声道、电平探针），每台物理设备共享单一 `AudioDeviceSink` 混音与防削波限幅总线。
- **新增** 音频图拓扑规划器（`AudioGraphPlanner`）与路由因果解释（`AudioRouteExplanation`），并写入本地诊断报告；支持无锁环形缓冲、自适应三次插值时钟漂移重采样及 20ms 无缝路由交叉淡入淡出。
- **修复** 关闭应用音效或对比原声时的动态增益跳变、菜单栏模式下独立音效窗口焦点与输入失效、聆听统计损坏崩溃与退出丢数据、蓝牙连接守卫失效对象误判及更新子进程管道阻塞问题。

**English**

- **Added** Introduced the `AuxmoAudioEngine` real-time audio graph core: each app runs as an independent `AudioAppSource` node chain (capture, gain/mute, EQ, spatial, dynamics/channel, and meter probe), while each physical output device shares a single `AudioDeviceSink` summing and safety-limiting bus.
- **Added** Added deterministic graph planning (`AudioGraphPlanner`) and causal route explanations (`AudioRouteExplanation`) in local diagnostics, backed by lock-free broadcast ring buffers, cubic drift-compensating resampling, and 20ms click-free route crossfading.
- **Fixed** Fixed dynamics bypass gain jumps, effect window keyboard focus in menu bar mode, listening statistics corruption crashes and exit data loss, stale Core Audio object false negatives in headphone guards, and update helper pipe deadlocks.
