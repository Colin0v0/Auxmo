**中文**

- **修复** 系统休眠前暂停的应用音量会在唤醒后自动恢复，不再让 Chrome 等应用永久显示红色错误标记或要求手动重新应用。
- **修复** 唤醒后应用混音会话会重新绑定当前已确认的输出设备，避免沿用休眠前已断开的设备 UID。
- **改进** 将休眠暂停与真实音频处理失败分开记录，权限、路由、音频格式和资源清理错误仍要求明确处理，不会被自动恢复误清除。

**English**

- **Fixed** App volume paused before system sleep now recovers automatically after wake, so Chrome and other apps no longer remain marked with a red error or require manual reapplication.
- **Fixed** Waking the Mac now rebinds app mixing sessions to the currently confirmed output instead of retaining a device UID from before sleep.
- **Improved** Sleep suspension is tracked separately from real audio-processing failures. Permission, routing, format, and cleanup errors still require explicit handling and are not cleared automatically.
